Build a complete, production-quality web application called **“AI Crop Doctor”**.

This is a **multilingual, voice-first AI agricultural assistant** for farmers.

The application should allow a farmer to:

1. Select or automatically detect their preferred language.
2. Use the entire website in that language.
3. Speak to the AI instead of typing.
4. Upload or capture a crop/leaf image.
5. Get AI-based crop disease detection.
6. Describe crop symptoms through voice.
7. Ask follow-up questions conversationally.
8. Receive treatment and prevention guidance.
9. Hear AI responses using text-to-speech.
10. View previous diagnoses.
11. Use the application easily on a mobile phone.

The design should be **modern, premium, floating, glassmorphism-based and AI-startup-like**, not a generic agricultural website.

# 5. CENTRALIZED TRANSLATION SYSTEM

Create a proper translation structure.

For example:

```text
src/
  i18n/
    index.ts
    translations/
      en.ts
      hi.ts
      mr.ts
      bn.ts
      gu.ts
      ta.ts
      te.ts
      kn.ts
      ml.ts
      pa.ts
      or.ts
      as.ts
```

Use translation keys instead of hardcoded UI strings.

Example:

```typescript
t("home.hero.title")
t("home.hero.subtitle")
t("detect.upload")
t("detect.analyze")
t("results.disease")
t("results.confidence")
t("results.treatment")
```

Every visible UI string must come from the translation system.

Do not write:

```tsx
<button>Upload Image</button>
```

Instead use:

```tsx
<button>{t("detect.upload")}</button>
```
